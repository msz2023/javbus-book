# 桌面程序生成
整体要求：请生成一个桌面端程序，需要包括后续的相关内容

## 对影片进行爬取
根据网页的每一页进行爬取，同时根据网页端的页数映射到桌面程序中

## 展示影片的具体内容
主要包括网页端的封面，以及网页中的：名字，識別碼；發行日期；導演；類別；演員以及磁力名稱等网页中的相关内容

## 提供bt种子
根据爬取到的网页中的磁力链接，也展示到桌面端中，点击之后像网页端一样可以调用本机中的相关下载工具

## 显示下载进度
若调用本机中的相关下载工具，显示下载进度等相关内容

## 调用本机播放器进行影片播放
调用本机默认播放器进行文件播放

## 可以显示哪个下载了哪个没下载

## 可以根据導演；類別；演員等类别进行分类筛选
